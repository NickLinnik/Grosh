## Slice 16: Transaction reprocessing — backup, delete, replay

**Design:** Implement the reprocessing job per `references/adr-transaction-reprocessing.md`. Reads existing transactions from DB, reconstructs `NormalizedTransaction` from stored columns (including `rate_source`), backs up to `reprocessing_backups`, deletes originals, publishes to `normalized_transactions` for fresh pipeline processing. Uses `pg_advisory_xact_lock` for mutual exclusion with the pipeline consumer. Verification via Kafka offset tracking.

- [ ] Add advisory lock to pipeline consumer — in `consumers/pipeline_consumer.py`, wrap the entire handler transaction (INSERT + transfer detection + anomaly recording) with `SELECT pg_advisory_xact_lock(hashtext('reprocess:' || $user_id))`. - [ ] Create NormalizedTransaction reconstruction function — `jobs/reconstruct.py`: given a transaction DB row, reconstruct `NormalizedTransaction` by mapping stored columns back to the model fields. - [ ] Create reprocessing job — `jobs/run_reprocess.py`: accepts optional `user_ids` param (default: all users).
